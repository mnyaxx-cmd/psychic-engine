# Phasmophobia x R.E.P.O. Mashup

**Машап для Melty**, превращающий охоту на призраков в опасную эвакуацию лута.

* **Геймплей:** Сканируйте вещи датчиками из Phasmophobia. Ценный лут злит призрака и снижает рассудок.
* **Цель:** Определить призрака, вынести дорогие артефакты и сбежать в фургон.

*Требуются оригинальные Phasmophobia и R.E.P.O. в Steam.*
